Installation Guide

Follow these simple steps to install Verteon in VS Code.

Step-by-step Installation

1

Step 1: Download the .vsix

Download Verteon 0.2.0 VSIX file from the download page.

local-ai-agent-0.1.0.vsix
2

Step 2: Open VS Code

Launch Visual Studio Code on your local machine.

✓ File → Open Folder
✓ File → Open File
3

Step 3: Open Extensions

Navigate to Extensions view from the Activity Bar on the left.

View → Extensions (Ctrl+Shift+X)
Or press Ctrl+Shift+X
4

Step 4: Install from VSIX

Click the extensions icon (⭲) and select "Install from VSIX...".

Extensions → Install from VSIX...
5

Step 5: Select the .vsix file

Browse and select the downloaded Verteon .vsix file, then click Install.

Browse → Select file → Install
6

Step 6: Open Verteon from Sidebar

After installation, open Verteon from the AI Agent section in the Activity Bar.

AI Agent → AI Agent
You're ready to start coding with AI!
