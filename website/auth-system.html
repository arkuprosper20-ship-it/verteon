Client-Side Authentication System

Clean session management architecture for Verteon website.

Authentication Architecture

User Flow

1

Create Account

User signs up via signup.html with validated form

2

Sign In

User logs in via signin.html, credentials validated

3

Session Persistence

Session stored in localStorage, persists across page reloads

4

Protected Routes

Dashboard and user pages require authentication check

Core Functions

isAuthenticated()
Checks if user is logged in by looking for user token in localStorage
login(userData)
Stores user session data in localStorage with expiration
logout()
Removes user session from localStorage and redirects to home
requireAuth()
Redirect to sign in if user is not authenticated
protectPage(pagePath)
Wrapper function to protect specific pages from unauthenticated access

Implementation Example

// auth.js - Client-side authentication
function isAuthenticated() {
    const user = localStorage.getItem('verteon_user');
    const token = localStorage.getItem('verteon_token');
    return !!(user && token);
}

function login(userData, token) {
    localStorage.setItem('verteon_user', JSON.stringify(userData));
    localStorage.setItem('verteon_token', token);
    localStorage.setItem('verteon_login_time', Date.now().toString());
}

function logout() {
    localStorage.removeItem('verteon_user');
    localStorage.removeItem('verteon_token');
    localStorage.removeItem('verteon_login_time');
    window.location.href = 'index.html';
}

function requireAuth() {
    if (!isAuthenticated()) {
        window.location.href = 'signin.html';
        return false;
    }
    return true;
}

function protectPage() {
    if (!requireAuth()) {
        return;
    }
    // Page content only loads if authenticated
    loadDashboard();
}
