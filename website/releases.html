Changelog

All notable changes to the Verteon VS Code extension.

v0.2.0
2026-10-05 View on GitHub

Major feature release — three-column workspace, multi-provider, safety system

  • Workspace: Three-column layout with sidebar, agent workspace, and live activity panel
  • Providers: Ollama (local, default) and Groq (cloud) with live health checks
  • Tools: 32 tools across filesystem, editor, terminal, project, build/test/lint, git
  • Safety: Three-tier command classification (safe, approval, blocked)
  • Secrets: Redaction + sensitive-file refusal, keys in VS Code SecretStorage
  • Diff review: Native VS Code diff before edits apply
  • History: Conversation restore and project memory
  • Responsive: Drawers on mobile, three columns on desktop
v0.1.0

  • Ollama provider with local model support
