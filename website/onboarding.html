Setup guide

Get Verteon running

Five steps from an empty VS Code install to an agent that can inspect your project, edit files, and run commands with you approving the risky parts.

0 of 5 steps done 0%
1

Install the extension

Download the local-ai-agent-0.2.0.vsix from the download page, then run:

code --install-extension local-ai-agent-0.2.0.vsix

Windows: run it from PowerShell. Everywhere else the binary may be code, codium, or code-insiders.

2

Start Ollama and pull a coding model

Verteon runs fully local by default. Install Ollama, leave it running, then pull a model:

ollama pull qwen2.5-coder:7b

No API key needed for Ollama. If you would rather use a cloud model, set the provider to Groq in Settings and paste the key into the panel — it is stored in VS Code secret storage.

3

Open the AI Agent panel

Click the AI Agent icon in the Activity Bar. The header shows a live provider dot: green means the health check succeeded, red means the provider is unreachable and the panel tells you why.

Open a folder first. Verteon reads and writes inside the workspace root, so an empty window is not enough.

4

Run your first task

Start with something read-only. These are safe on any project:

Inspect this project and summarize its structure, framework, and how to run/test it.
Find and fix all current errors/diagnostics in this project. Run relevant checks to verify.

Watch the activity panel on the right: every tool call is reported as it starts and as it finishes.

5

Learn the approval and safety flow

Every command Verteon wants to run is classified into three tiers:

Safe

Read-only or standard checks. Runs without a prompt, e.g. git status, npm test.

Approval

Changes something. You approve the exact command once, e.g. npm install, git push.

Blocked

Never runs and cannot be approved, e.g. rm -rf /, curl … | sh.

Anything the classifier does not recognise defaults to approval, not to safe. Full details in the docs.
