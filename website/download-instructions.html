Install

Install Verteon 0.2.0

Three steps: get the .vsix, install it with one command, confirm it is running.

1. Get the VSIX file

The extension ships as a packaged local-ai-agent-0.2.0.vsix. Download it directly:

Download VSIX (0.16 MB)

Or build it yourself from the public source:

git clone https://github.com/arkuprosper20-ship-it/verteon.git
npm install
npm run package

That produces local-ai-agent-0.2.0.vsix in the project root. Run the next command from that same folder, or pass the full path to the file.

2. Install it

From a terminal, in the folder containing the VSIX:

code --install-extension local-ai-agent-0.2.0.vsix

Windows

Run from PowerShell. If code is not recognised, VS Code adds it to PATH on first install; otherwise use the full path to Code.exe.

macOS / Linux

The binary is code, codium for VSCodium, or code-insiders. The Shell Command: Install 'code' command in PATH command from the Command Palette sets this up.

3. Confirm it is running

Reload the window (Developer: Reload Window). The AI Agent icon appears in the Activity Bar. On first launch Verteon probes your provider: with Ollama running you get a success message, and without it a warning with shortcuts to Settings and the Ollama download.

You can also check from the CLI:

code --list-extensions | grep local-ai-agent

On PowerShell, use Select-String in place of grep.
